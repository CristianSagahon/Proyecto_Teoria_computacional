│ 🤖  9. AFN → AFD (CONSTRUCCIÓN POR SUBCONJUNTOS)
└────────────────────────────────────────────────────────────────────────
  ℹ  Σ = {o, t}: o = OK, t = TIMEOUT. Se acepta (Falla) si termina en 'tt'.

▸ AFN  N = (Q, Σ, δ, q0, F)
  Q: {q0, q1, q2}
  Σ: {o, t}
  q0: q0
  F: {q2}
  ┌────┬──────┬─────────┐
  │ δ  │ o    │ t       │
  ├────┼──────┼─────────┤
  │ q0 │ {q0} │ {q0,q1} │
  │ q1 │ ∅    │ {q2}    │
  │ q2 │ ∅    │ ∅       │
  └────┴──────┴─────────┘

▸ Procedimiento de subconjuntos
  Estado inicial del AFD: A = {q0}

  Procesando A = {q0}:
    δ'(A, o) = δ(q0,o)={q0} = {q0} = A
    δ'(A, t) = δ(q0,t)={q0,q1} = {q0,q1} = B  ← conjunto NUEVO

  Procesando B = {q0,q1}:
    δ'(B, o) = δ(q0,o)={q0} ∪ δ(q1,o)=∅ = {q0} = A
    δ'(B, t) = δ(q0,t)={q0,q1} ∪ δ(q1,t)={q2} = {q0,q1,q2} = C  ← conjunto NUEVO

  Procesando C = {q0,q1,q2}:
    δ'(C, o) = δ(q0,o)={q0} ∪ δ(q1,o)=∅ ∪ δ(q2,o)=∅ = {q0} = A
    δ'(C, t) = δ(q0,t)={q0,q1} ∪ δ(q1,t)={q2} ∪ δ(q2,t)=∅ = {q0,q1,q2} = C

  Estados finales del AFD (contienen q2): C

▸ Tabla del AFD   (→ inicial, * final)
  ┌────────┬──────────────────┬───┬───┐
  │ Estado │ Conjunto del AFN │ o │ t │
  ├────────┼──────────────────┼───┼───┤
  │ → A    │ {q0}             │ A │ B │
  │   B    │ {q0,q1}          │ A │ C │
  │  *C    │ {q0,q1,q2}       │ A │ C │
  └────────┴──────────────────┴───┴───┘

  ✔  AFN y AFD son equivalentes: aceptan lo mismo en las 511 cadenas de longitud 0 a 8
